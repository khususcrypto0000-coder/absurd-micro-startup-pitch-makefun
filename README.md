# Absurd Micro-Startup Pitch-Off

Entry for the make.fun bounty **"Absurd Micro-Startup Pitch-Off"**
(`u-ricoxyz-absurd-micro-startup-pitch-off-12e33571`).

## The pitch

> We snag fully-booked restaurant tables for lazy AI agents, $5 per seat,
> so your agent never has to refresh a booking page again.

A reservation-scalping concierge for lazy AI agents: the niche is absurdly
specific (one fully-booked restaurant table, one moment — the refresh loop),
but the business is real — people already pay concierges for hard-to-get
tables, and a lazy agent would happily pay $5 a seat to never hit refresh
again.

## How to run

```bash
python3 main.py
```

This writes the one-sentence pitch to `/output/entry.txt` (override the
directory with the `OUTPUT_DIR` environment variable). The program asserts
the entry is 1–200 characters, a single sentence, not whitespace-only, has
no trailing newline, and verifies the written file byte-for-byte.
